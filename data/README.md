# Data

`data/raw/` and `data/processed/` are **not tracked in this repository** (see the top-level `.gitignore`). Combined, the raw downloads and processed intermediate files total approximately 1.4 GB, with individual files up to 386 MB — well over typical code-hosting per-file limits. Every file below is fully public and free to download; no data use agreement (DUA), institutional review board approval, or account registration beyond a free NCBI/Zenodo account (not even required for anonymous FTP/HTTP download) is needed.

## 1. GEO series matrices

Download each series matrix directly from NCBI GEO (no login required):

| Accession | Direct download | Used for |
|---|---|---|
| GSE33000 | [GEO page](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE33000) → Series Matrix File(s) | Stage-1 mRNA primary training cohort |
| GSE44770 | [GEO page](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE44770) → Series Matrix File(s) | Stage-1 mRNA primary training cohort |
| GSE80970 | [GEO page](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE80970) → Series Matrix File(s) | Stage-2 methylation primary training/CV cohort |
| GSE118553 | [GEO page](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE118553) → Series Matrix File(s) | Stage-1 external validation cohort #1 |
| GSE5281 | [GEO page](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE5281) → Series Matrix File(s) | Stage-1 external validation cohort #2 |
| GSE134379 | [GEO page](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE134379) → Supplementary files (processed per-region/diagnosis beta-value files) | Stage-2 external validation cohort |

Save each `*_series_matrix.txt.gz` into `data/raw/` under the filename referenced above. For GSE134379, `scripts/12_process_gse134379_methylation.py` expects the processed supplementary beta-value files (`GSE134379_processedSamples_mtgAD.txt.gz`, `GSE134379_processedSamples_mtgND.txt.gz`) rather than the series matrix — download these from the GEO "Supplementary file" section.

## 2. Platform annotation files

- **GPL570** (Affymetrix HG-U133 Plus 2, used by GSE5281): download the `.annot.gz` annotation file from its [GEO platform page](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GPL570).
- **GPL10558** (Illumina HumanHT-12 v4, used by GSE118553): download the `.annot.gz` annotation file from its [GEO platform page](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GPL10558).
- **GPL13534** (Illumina HumanMethylation450, used by GSE80970 and GSE134379): download the manifest CSV from its [GEO platform page](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GPL13534) or the [Illumina product support page](https://support.illumina.com/array/array_kits/infinium_humanmethylation450_beadchip_kit/downloads.html).

## 3. Curated gene panel (Zenodo)

The 16,193-gene feature panel and primary Stage-1 sample-level feature table (`gene_data.csv`) used as the primary training input are sourced from the AE-Trans reproducibility archive on Zenodo:

**[https://doi.org/10.5281/zenodo.13933763](https://doi.org/10.5281/zenodo.13933763)** (Huang, 2024), released under **CC-BY-4.0**.

Download `gene_data.csv` (and `methylation_data.csv`, used for the Stage-2 gene-mapped methylation panel) from this archive into `data/raw/`.

## 4. Regenerating processed data

Once all raw files above are in `data/raw/`, run the preprocessing scripts in order:

```bash
cd scripts
python 01_inspect_data.py                       # sanity-check downloads
python 02_full_characteristics.py                # locate diagnosis labels
python 03_process_external_validation.py         # GSE118553 → data/processed/
python 04_align_external_features.py             # align GSE118553 features to primary panel
python 12_process_gse134379_methylation.py       # GSE134379 → data/processed/
python 13_process_gse5281_mrna.py                # GSE5281 → data/processed/
```

This regenerates every file that would otherwise live in `data/processed/` (parquet expression matrices, aligned external-validation CSVs, sample metadata). From there, `scripts/05` through `scripts/17` reproduce every result and figure reported in the manuscript.

## No controlled-access data

No file in this project comes from a controlled-access repository (ROSMAP, ADNI, AMP-AD Knowledge Portal, AD Sequencing Project, UK Biobank, or similar). This was a deliberate constraint of the study design so that every result is independently reproducible by any reader without a data use agreement or institutional approval process — see the manuscript's Data Availability Statement (Section 7) and Limitations (Section 5) for further discussion.
